# GraphRAG 기반 공급망 리스크 탐지 시스템

---

## 1 - 프로젝트 소개

### 한 줄 요약
뉴스·협력사·관세 데이터를 지식 그래프로 연결해, 현대자동차 공급망 리스크를 자동으로 탐지하는 GraphRAG 시스템 구축

### 문제 정의
현대자동차의 공급망 데이터(뉴스 / 협력사 DB / 관세 데이터)는 각 팀에 분산되어 **서로 연결되어 있지 않음**
→ 리스크 발생 시 즉각 파악 불가, 전문가가 수동으로 연결·분석

일반 RAG로는 **"알루미늄 단가 급등 → 영향받는 협력사 → 타격받는 전기차 모델"** 같은 다단계 인과관계 추적이 불가능
→ 데이터를 하나의 지식 그래프로 연결하는 **GraphRAG**로 해결

### 시스템 구조
```
뉴스(1,134건) + 협력사(900개사) + 수입관세(562건)
           ↓  LLMGraphTransformer (GPT-4o-mini)
      Neo4j 지식 그래프 자동 구축
           ↓  하이브리드 검색 (벡터 + 그래프 k-hop)
      GPT-4o 리스크 분석 답변 생성
           ↓
  FastAPI + vis.js 실시간 대화형 데모
```

### 핵심 기술
`Neo4j AuraDB` `LangChain / LangGraph` `GPT-4o` `Claude Opus` `FAISS` `FastAPI` `RAGAS`

## 2 — 구현 및 성과

### 주요 구현 내용

**① 온톨로지 직접 설계**
뉴스에서 추출할 Entity 10종(Company / Competitor / Supplier / RiskCategory / Event / Strategy / SupplyItem 등)과 Relation 9종(CAUSES / AFFECTS / SUPPLIES\_TO 등)을 직접 정의
→ LLM이 리스크 인과관계를 일관된 스키마로 추출하도록 유도

**② 환각 방지 설계**
Text-to-Cypher 대신 LLM을 엔티티 추출기로만 사용하고, 그래프 탐색(Cypher)은 하드코딩
→ 모든 답변에 원문 뉴스 링크를 근거로 매핑

**③ 하이브리드 검색**
벡터 유사도(의미 검색) + BM25 키워드(고유명사 정확도)를 결합
→ "삼아알미늄", "HS코드" 같은 고유명사도 정확히 탐색

**④ 데이터 전처리 파이프라인**
자카드 유사도 80% 기준 중복 제거 → 노이즈·이모지 정제 → 엔티티 표기 통일 → 도메인 외 기사 필터링
→ 원본 1,275건 → 고품질 1,134건

### 성능 평가 (RAGAS)

| 지표 | 일반 RAG | GraphRAG |
|---|---|---|
| 충실도 (Faithfulness) | 0.384 | **0.541** (+41%) |
| 답변 관련성 (Answer Relevancy) | 0.462 | **0.474** |

### 실제 질의응답 예시

> Q. "알루미늄 단가가 급등하면 어떤 협력사가 타격받아?"
> → 삼아알미늄·남선알미늄·알루코 등 **10개사 리스크 높음** 자동 판정 + 근거 뉴스 링크 제공

> Q. "삼아알미늄 원가 부담이 커지면 어떤 전기차 모델이 타격받아?"
> → **현대 아이오닉 5** (알루미늄 사용 비율 높은 전기 SUV) 생산 단가에 가장 큰 영향

**뉴스 → 원자재 → 협력사 → 완성차 모델** 4단계 인과관계를 자동 추론

### 한계 및 개선 방향
- 현재 1차 협력사만 포함 → 2·3차 협력사까지 확장 시 연쇄 리스크 추론 가능
- 내부 구매 데이터 연동 시 부품-원자재-공정 연결로 분석 정밀도 대폭 향상 기대
